APP REVIEW EXPLANATION — COPY INTO THE 1000 CHARACTER FIELD
M.M.F Publisher is a creator-focused web application that lets an authorized user connect a TikTok account using Login Kit, select video content they own or are authorized to publish, review the publishing settings, and explicitly submit the post to TikTok using the Content Posting API. Login Kit is used only for TikTok authentication and the user.info.basic scope is used to identify the connected account and show the authorized profile in the publishing interface. The video.publish scope is used only after the user selects a video and confirms the publishing action. The application does not publish in the background or without user action. The review demo shows the complete flow in the TikTok Sandbox: open the website, connect TikTok, approve consent, return to M.M.F Publisher, select media, review settings, confirm publishing, and display the publishing result/status.

URL VERIFICATION
TikTok requires verification for configured website/privacy/terms URLs and Content Posting related URL properties. Use TikTok Developer Portal > URL properties. Verify the GitHub Pages URL prefix or, preferably, a dedicated custom domain later. TikTok may provide a signature file; place that exact file in the published site root and verify it in the portal.

IMPORTANT
Do not submit for production review before the Login Kit + Content Posting flow is genuinely functional. TikTok states that apps still in development/testing and apps described as private/personal-only will not be approved.
