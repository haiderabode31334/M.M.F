A personal content-management tool that helps its authorized user select, prepare and publish video content to TikTok using TikTok's official Login Kit and Content Posting API. Publishing is performed only after an explicit user action.

What the app does

Secure sign-inConnects an authorized TikTok account through TikTok Login Kit.
Media selectionLets the user choose video content that they own or are authorized to publish.
PublishingSends user-approved content through TikTok's official Content Posting API.
User controlThe user chooses the content and initiates every publishing action.
